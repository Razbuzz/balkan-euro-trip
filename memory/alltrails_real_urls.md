### 3. Trem Summit from Popova Šapka (Šar Mountains, North Macedonia)
**File:** `src/day7_skopje_trem_summit.md`
**Status:** PARTIAL — No dedicated "Trem Summit" trail confirmed on AllTrails
- **AllTrails result (wrong location):** https://www.alltrails.com/trail/serbia/nisavski-upravni-okrug/trem-summit — This is in Serbia's Nišavski district (wrong region)
- **Wikiloc (best available):** https://www.wikiloc.com/hiking-trails/popova-sapka-plat-popova-sapka-62545527

  - Peak elevation: 2,308m (Plat)
  - **Note:** The Wikiloc "Plat" summit is not the same as "Trem Summit" — Plat is a different peak in the Šar Mountains ski resort area. Trem Summit (Trem) is a separate peak in the Šar Mountains near Kosovo border.
- **AllTrails POI:** https://www.alltrails.com/explore/poi/kosovo/dragash/popova-sapka--2075- (Popova Šapka ski resort POI in Kosovo)
- **Platform:** AllTrails + Wikiloc — No confirmed dedicated Trem Summit trail found on AllTrails for Šar Mountains
